GitHub wordt ingezet voor het beheren en organiseren van projectgegevens en verzamelde data, zodat alle informatie op een gestructureerde en overzichtelijke manier wordt weergegeven. Door gebruik te maken van een duidelijke mappenstructuur—met specifiek onderscheid tussen ruwe data, verwerkte data, resultaten en scripts—is het eenvoudig om snel te vinden wat je zoekt.
Een van de belangrijkste redenen voor het gebruik van GitHub is het bevorderen van de reproduceerbaarheid van het onderzoek. Omdat bijna alle benodigdheden op één plek te vinden zijn, kunnen anderen het onderzoek simpel nadoen: door bijvoorbeeld het gebruikte genoom te downloaden en de geannoteerde code stap voor stap te volgen, kunnen zij controleren of hun resultaten overeenkomen met de bijgevoegde figuren. De scripts bevatten tekstuele toelichtingen en annotaties (#) die precies uitleggen wat elke stap in de code doet.
Daarnaast biedt GitHub specifieke voordelen voor documentatie en beheer:

    Gecombineerde informatie: Uitleg die normaal gesproken in een apart verslag staat, bevindt zich nu direct bij de relevante bestanden. Het README.md-bestand fungeert hierbij als centraal punt met hyperlinks naar methoden, resultaten en bronnen.
    Versiebeheer: Via GitHub Desktop wordt elke aanpassing in de scripts of de README bijgehouden. Hierdoor zijn wijzigingen altijd te volgen en is de meest recente versie van het onderzoek direct beschikbaar.
    Delen en citeren: Dankzij de citatie-functie is de pagina eenvoudig bruikbaar voor anderen die inzicht willen krijgen in het onderzoek of er op voort willen bouwen.
